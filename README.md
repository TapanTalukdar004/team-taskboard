# Team TaskBoard

A tiny task-list web app used to practice the real company workflow:
**Linear issue → branch → code → commit → push → Pull Request → review → merge → auto-close issue.**

## Run it
No installs. Double-click `index.html` (or right-click → Open with → browser).

## v1 (this baseline)
- Type a task, press **Add** (or Enter) → it appears in the list.

## Roadmap (delivered through Linear issues)

| AB-4 | Survive refresh (localStorage) | Feature |

## Files
- `index.html` — page structure
- `style.css` — styling (incl. the `.done` class AB-1 uses)
- `script.js` — the logic you'll be editing
- `ISSUES_TO_CREATE.md` — paste-ready Linear issues
- `STEP_GUIDE.md` — the full beginner git guide (every command + what you should see)
